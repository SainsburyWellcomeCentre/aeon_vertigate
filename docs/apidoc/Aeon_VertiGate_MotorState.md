[DisableMotor](xref:Aeon.VertiGate.ControlFlags.DisableMotor) and [EnableMotor](xref:Aeon.VertiGate.ControlFlags.EnableMotor) set this state. While the motor is off, the device refuses each write to [TargetPosition](xref:Aeon.VertiGate.TargetPosition) and each [Calibrate](xref:Aeon.VertiGate.ControlFlags.Calibrate) command.
